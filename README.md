# Лабораторна робота №3 (Java Stream API, Optional & Stream Gatherers)

## Опис проєкту

Загалом реалізовано проєкт який є сервісом аналітики безпекових подій у реальному часі. 
Основний функціонал зосереджено в класі `SecurityLogAnalyzer`, який забезпечує пошук першої критичної події за допомогою операцій короткого замикання, фільтрацію логів за часовим вікном за допомогою оператора `takeWhile`, а також детекцію атак типу `Burst` через кастомний `Stream Gatherer`.
Алгоритм детекції атак відстежує послідовні серії запитів від однієї IP-адреси, скидає стан при розриві послідовності та обмежує кількість результатів у звіті. 
Залежностями в проєкті керує `Gradle`, а працездатність підтверджено юніт-тестами на `JUnit 5` із використанням нескінченних генераторів `Stream.generate`.

## Інструкція із запуску та тестування

> Для збірки проєкту та виконання тестів потрібна встановлена JDK 21+

Запуск повної збірки проєкту:

```bash
./gradlew build
```

Запуск юніт-тестів:

```bash
./gradlew test
```
